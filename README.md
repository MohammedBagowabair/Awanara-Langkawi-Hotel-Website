# Awanara Langkawi

Single-page website for Awanara Langkawi, an island sanctuary hotel concept at Teluk Datai, Langkawi, Malaysia.

- Stack: Vite + React + Tailwind CSS
- Contact: WhatsApp [+60 11-5119 8497](https://wa.me/601151198497)
- Live: https://mohammedbagowabair.github.io/Awanara-Langkawi-Hotel-Website/

```bash
npm install
npm run dev
BASE_PATH=/Awanara-Langkawi-Hotel-Website/ npm run build   # outputs dist/
```
